# 📊 Projeto de Análise de Dados - Superstore

## 📌 Sobre o Projeto

Este projeto foi desenvolvido durante o curso de **Análise de Dados - SCTEC/SESI**, com o objetivo de aplicar técnicas de tratamento, exploração e visualização de dados utilizando Python.

A análise foi realizada sobre o dataset **Superstore**, contendo informações de vendas, clientes, produtos, categorias e regiões, buscando identificar padrões, indicadores de desempenho e oportunidades de melhoria.

---

## 🎯 Objetivos

* Realizar a exploração inicial dos dados;
* Efetuar limpeza e tratamento das informações;
* Analisar indicadores de vendas e desempenho;
* Identificar os produtos e categorias mais relevantes;
* Gerar insights através de análises estatísticas e visualizações;
* Desenvolver habilidades práticas em análise de dados com Python.

---

## 📈 Etapas da Análise

### 1. Importação dos Dados

1.1 - Carregamento do dataset;
1.2 - Visualização e Compreensão dos dados.

### 2. Tratamento e Preparação dos Dados

2.1 - Verificaçao de valores nulos;
2.2 - Verificaçao de registros duplicados;
2.3 - Conversão de tipos de dados;
2.4 - Padronização dos nomes da Colunas.

### 3. Análise Exploratória dos Dados Indicarodores e gráficos

3.1 - Valores Discrepantes de Vendas (Gráfico Boxplot);
3.2 - Total de vendas por categoria (Gráfico de barras);
3.3 - Total de vendas por segmento (Gráfico de barras);
3.4 - Relação entre Desconto e Lucro (Gráfico de dispersão - Scatter Plot).

## 📊 Principais Resultados

A análise permitiu compreender o comportamento das vendas e identificar informações relevantes sobre:

* Categorias com maior participação;
* Regiões com melhor desempenho;
* Produtos mais vendidos;
* Relação entre vendas e lucratividade.

## 🚀 Como Executar o Projeto

### 1. Clone o repositório

```bash
git clone https://github.com/jhonatasilva1902/projeto-analise-exploratoria-dados.git
```

Entre na pasta do projeto:

```bash
cd projeto-analise-exploratoria-dados
```

## 2. Crie um ambiente virtual

Windows:

```bash
python -m venv venv
```

---

## 3. Ative o ambiente virtual

PowerShell:

```powershell
.\venv\Scripts\Activate.ps1
```

---

## 4. Instale as dependências

```bash
pip install -r requirements.txt
```

---

## 5. Abra o projeto no Visual Studio Code

Abra a pasta do projeto e, em seguida, abra o arquivo:

```
analise_superstore.ipynb
```

---

## 6. Selecione o ambiente Python (Kernel)

No canto superior direito do notebook, clique sobre o interpretador Python (Kernel).

Caso apareça uma versão diferente da utilizada no projeto, selecione o ambiente virtual criado anteriormente (`venv`).

> **Observação:** na primeira execução, o VS Code poderá instalar automaticamente alguns componentes do Jupyter. Aguarde a conclusão antes de continuar.
> Veja as telas na pasta Imagens

---

## 7. Execute o notebook

Após selecionar o ambiente virtual, clique em **Run All** para executar todas as células na ordem em que aparecem.
